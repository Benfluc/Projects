# Plataforma de Análise da Fórmula 1 
### Uma plataforma completa de Business Intelligence para dados históricos da Fórmula 1, desenvolvida com Python, PostgreSQL, Docker, SQL e Power BI.
##
<br>

## Visão Geral

Este projeto demonstra um fluxo completo de Business Intelligence, desde a coleta de dados públicos da Fórmula 1 e a construção de um banco de dados PostgreSQL utilizando Docker até o desenvolvimento de dashboards interativos e análises visuais no Power BI.

## Objetivos

Desenvolver uma plataforma completa de Business Intelligence para dados históricos da Fórmula 1. O projeto combina automação em Python, PostgreSQL, Docker, SQL e Power BI para construir uma solução analítica de ponta a ponta, desde a inicialização do banco de dados e atualização das temporadas até a criação de dashboards interativos e análises de desempenho.

## Tecnologias

- **PostgreSQL** – Sistema de gerenciamento de banco de dados relacional
- **Docker** – Conteinerização do banco de dados
- **SQL** – Consultas e transformação de dados
- **Python** – Automação de ETL, limpeza de dados, coleta de imagens e geração do banco de dados
- **Power BI** – Modelagem de dados e desenvolvimento de dashboards
- **DAX (Data Analysis Expressions)** – Criação de medidas e colunas calculadas

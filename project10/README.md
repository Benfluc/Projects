# CineStack: An end-to-end application built from a custom SQLite database, featuring a Python REST API and a responsive React frontend.

## Overview
An end-to-end full stack application that showcases the complete development of a movie search platform, including custom SQLite database design, a Python REST API, and a responsive React frontend.

## Objective
Develop an end-to-end full stack movie search platform, covering the complete software development lifecycle—from SQL database design and implementation to backend API development and a responsive web interface.

## Technologies

- **Database:** SQLite, SQL
- **Backend:** Python, FastAPI, SQLAlchemy
- **Frontend:** React, JavaScript, HTML5, CSS3
- **Data Format:** JSON
- **Tools:** Git, GitHub, VS Code

# CineStack: Uma aplicação ponta a ponta construída a partir de um banco de dados SQLite personalizado, com uma API REST em Python e um frontend responsivo em React.

## Visão Geral

Uma aplicação full stack ponta a ponta que demonstra o desenvolvimento completo de uma plataforma de consulta de filmes, incluindo a modelagem e implementação de um banco de dados SQLite personalizado, uma API REST em Python e uma interface web responsiva desenvolvida em React.

## Objetivo

Desenvolver uma plataforma full stack de consulta de filmes, abrangendo todo o ciclo de desenvolvimento de software, desde a modelagem e implementação do banco de dados em SQL até o desenvolvimento da API backend e de uma interface web responsiva.

## Tecnologias

- **Banco de Dados:** SQLite, SQL
- **Backend:** Python, FastAPI, SQLAlchemy
- **Frontend:** React, JavaScript, HTML5, CSS3
- **Formato de Dados:** JSON
- **Ferramentas:** Git, GitHub, VS Code
